## Description
This website is a responsive web application built as an assignment for WaysAhead Global. It is developed using Vite, React, Tailwind CSS, and ESLint. The project features dynamic sections including Hero, Services, News, Contact, and an integrated AI-powered chatbot that assists with queries and guides users through the website. 
Used Puter AI instead of OpenAI API because it doesn't need API keys. When we start to chat, it may ask for user confirmation to proceed. We can click on Continue button to proceed.
